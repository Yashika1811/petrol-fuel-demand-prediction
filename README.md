# Petrol Pump Fuel Demand Prediction

## About the Project
This is a beginner-level Machine Learning project that predicts petrol demand using different factors such as temperature, previous day's sales, petrol price, month, and day of the week.

## Objectives
- Predict petrol demand using Machine Learning.
- Understand how different factors can affect fuel demand.
- Display demand trends using graphs.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Joblib

## Machine Learning Algorithm
Random Forest Regressor

## Project Features
- Creates a fuel demand dataset.
- Trains a Machine Learning model.
- Predicts petrol demand based on user input.
- Generates graphs to visualize demand.

## How to Run
1. Install Python and the required libraries.
2. Create the dataset by running `create_dataset.py`.
3. Train the model by running `train_model.py`.
4. Generate graphs by running `visualize_data.py`.
5. Predict demand by running `predict_demand.py`.

## Dataset Note
This project uses synthetic practice data created for learning purposes. Its predictions are not validated for real-world fuel purchasing or stock decisions.

## Learning Outcome
This project helped me understand data preparation, model training, prediction, and data visualization using Python.
